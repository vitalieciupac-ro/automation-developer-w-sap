# Getting Started

This is a **three-day, instructor-led course** for beginner UiPath Automation Developers. Over three days you go from building a simple sequence to building a reliable component of an enterprise automation, and you finish with SAP automation on both the web (Fiori) and the desktop (SAP GUI).

!!! info "Built for Studio 25.10.17"
    Every activity, selector, and expression in this course targets **UiPath Studio 25.10.17**.

## What you'll learn

The course runs over **three days**. Days 1 and 2 build the foundations across six modules; Day 3 applies them to SAP GUI automation.

| # | Module | You'll be able to… |
|---|--------|--------------------|
| 1 | [Studio, Orchestrator & Licensing](foundations/1-studio-orchestrator-licensing.md) | Install Studio, tour Orchestrator, and set up an attended license |
| 2 | [DataTables & Excel](foundations/2-datatables-excel.md) | Read, filter, and write tabular data |
| 3 | [Reliable UI Automation](foundations/3-ui-automation.md) | Automate SAP S/4HANA (Fiori) reliably across timing and change |
| 4 | [Debugging, Errors & Logging](foundations/4-debugging-errors.md) | Diagnose and handle failure gracefully |
| 5 | [Email & PDF](foundations/5-email-pdf.md) | Automate documents end-to-end |
| 6 | [Professional Projects](foundations/6-professional-projects.md) | Structure, analyze, and publish a project |

**Day 3** adds a SAP GUI (desktop) track: configuring SAP Logon, building the automation as small workflows, and a session on SAP and classic implementation best practices.

## Who this is for

Tech-savvy learners who are new to UiPath development. No prior RPA experience is needed: the course starts from installing Studio and builds up to reliable SAP automation on both the web and the desktop.

## What this course is and is not

It builds a foundation for real SAP automation work. It is **not** a full REFramework course, an Orchestrator administration course, or exam cramming. Where a topic goes deeper than the course allows, it is flagged as a *next step* rather than taught in full.

## The shape of the day

Each foundation module has two parts:

1. **Concept**: a short explanation of the idea and *why* it matters in production.
2. **Build it together**: the trainer shares their screen and builds the automation live while you build the same thing on your own machine, step by step. Each module includes a collapsible solution you can check against or use to catch up.

## By the end you'll be able to

- Install Studio, navigate Orchestrator, and configure a license for an attended run.
- Read, filter, and write tabular data with DataTables and the modern Excel activities.
- Build SAP S/4HANA (Fiori) automation that survives timing issues and screen changes.
- Debug methodically and handle errors with meaningful logging.
- Automate email and PDF tasks and combine them into an end-to-end process.
- Organize a project into reusable workflows, validate it with Workflow Analyzer, and publish it.
- Configure and automate the desktop SAP GUI, and apply SAP and classic implementation best practices.

## How to use this material

This course serves both the trainer and the learner. Each page carries the concept and the automation you build together, with the trainer sharing their screen while learners build the same thing on their machines. A collapsible solution accompanies each exercise for checking your work or catching up. Work through the setup, then the modules in order.

!!! autopilot "Autopilot is built in"
    UiPath Autopilot is the AI assistant built into Studio, included with your license. Where it genuinely helps, you'll find a teal Autopilot note that tells you exactly how to use it. Autopilot can make mistakes, so you always review and refine what it produces.
