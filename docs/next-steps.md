# Next Steps

You've built the foundation the rest of the Developer Associate path assumes. Here's where to go from here.

## Continue the learning plan

Work through the remaining **Automation Developer Associate** courses on UiPath Academy:

- Orchestrator resources (Assets, Queues, triggers) in depth
- UiPath Integration Service
- Version control systems integration
- RPA testing with Studio
- Project organization and the **Robotic Enterprise Framework (REFramework)**
- Automation implementation methodology

## Go further with Autopilot

You used Autopilot in a few places in this course. It runs across the rest of the platform too, so as you go deeper you'll find it in:

- **Orchestrator**, where it monitors job health and suggests fixes in plain language.
- **Test Manager**, where it generates tests from requirements and helps analyze results.
- **Maestro**, where it captures workflows from live systems and turns business requirements into process designs.

The same habit applies everywhere: describe what you want, then review and refine what Autopilot produces.

## Work toward certification

This course covers the **foundational objectives** of the **UiPath Certified Professional Automation Developer Associate** exam, but it isn't a substitute for the full learning plan. Complete the remaining courses, then sit the exam.

!!! tip "The fastest way to cement all of this"
    Automate **one real task from your own week** this month. Nothing fixes these skills in place like a live problem with a deadline: a report you assemble by hand, an inbox you triage, or a spreadsheet you reconcile.
